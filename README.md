# Chayakorn Portfolio — ไฟล์เดียว

ดับเบิลคลิก `index.html` ได้เลย หรือนำไฟล์นี้เพียงไฟล์เดียวไปวางบนเว็บเซิร์ฟเวอร์

HTML, CSS, JavaScript, React และรูปโปรไฟล์ฝังอยู่ในไฟล์ทั้งหมด ไม่ใช้ CDN ไม่โหลดฟอนต์ออนไลน์ และไม่ต้องติดตั้ง Node.js เพื่อเปิดดู ใช้ฟอนต์ภาษาไทยที่มีในเครื่อง เช่น Tahoma

ยังมีเมนูมือถือ ปุ่มคัดลอกข้อมูลติดต่อ การนำทางด้วยคีย์บอร์ด และการลดภาพเคลื่อนไหว อีเมลจะเปิดโปรแกรมอีเมลเมื่อคลิก หากเบราว์เซอร์ไม่อนุญาตให้คัดลอกจากไฟล์ในเครื่อง ระบบจะลองวิธีสำรองและแจ้งผล

## แก้ไขซอร์ส React + TypeScript + Tailwind CSS

โค้ดต้นฉบับเก็บใน `src/` และใช้ `app.html` เป็นหน้าสำหรับพัฒนา

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง ตามด้วย `/app.html` เช่น http://127.0.0.1:5173/app.html

เมื่อแก้ไขเสร็จ สร้างไฟล์เดียวใหม่ด้วย:

```sh
npm run build
```

คำสั่งนี้ตรวจ TypeScript แล้วรวมทุกอย่างลง `index.html` ที่รากโปรเจกต์ และสำเนา `dist/index.html` ไม่ต้องนำโฟลเดอร์ assets หรือ src ไปด้วย การติดตั้งแพ็กเกจสำหรับพัฒนาต้องใช้อินเทอร์เน็ต แต่ไฟล์เว็บที่สร้างแล้วเปิดใช้งานแบบออฟไลน์ได้

กราฟิกประตูมิติและยานเป็นภาพประกอบ ส่วนรูปโปรไฟล์ใช้ภาพที่เจ้าของเว็บให้มา
